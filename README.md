
## Pasos previos
1. Node.js instalado (versión 18.20.2)
2. Clonar el proyecto 
3. Descargar la rama main2 (Aquí se encuentran los cambios)

## Ejecutar el proyecto


1. Ejecutar la siguiente línea para bajar las dependencias
```bash
npm run dev
```

2. Acceder a la url http://localhost:3000 o a la que diga la terminal, en caso de tener el puerto ocupado
3. Para el inicio de sesión se tiene por default el usuario admin y la contraseña admin123
4. El registro, una vez escritos los campos, redirecciona al usuario, sin embargo aún no guarda dicho usuario por lo que se debe acceder con el paso anterior para poder ver como se maneja la sesión
5. El usuario tiene como nombre "admin"

Nota: La experiencia con el proyecto se detalla en el readme del api.
